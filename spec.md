
# Spec: Apple Quest Journey App


## Idea
An app that gives students developers a unique quest configured by mentors to learn about apple technology and framework through simple interactive experiences. The app will provide students an experiences to learn and explore more about the technology.

## Platform
- MacOS for the Mentors App
- iOS for the Developers App

## Problem
Learning Apple Technology and Framework is a taking a big effort. We want to simplify the process by letting the developers experienced the framework and saved the learning resources that has been provided by the mentor in everyday experience.

## The Features
- Pre-made custom expereinces that can be selected within the quest (Example: if i want an experiences about share play, then the premade experiences will ask the developer to use share play and do certain things like pressing a button then the other developer can see.)
- Mentors create the Quest consisting pre-made experiences, learning resources, and when is this publised to the developers
- Developers plays the custom experiences

## Outcome
- Mentors app manage and create the quest on when it is published
- Students app plays the experience and save it
